# Особистий сайт

Мета проєкту — представити інформацію про мене, мій досвід і захоплення та попрактикувати HTML і CSS. Це наявний сайт із попередніх занять, підготовлений для публікації через GitHub Pages.

## Технології

- HTML5 — структура трьох сторінок.
- CSS3 — оформлення сайту.

## Перевірка результату

Відкрийте `index.html` у браузері та перевірте переходи між сторінками, перехід до фотогалереї, відображення зображень і стилів. Після публікації на GitHub Pages повторіть ці перевірки за адресою сайту; контактна форма є навчальним прикладом і не надсилає повідомлень.
